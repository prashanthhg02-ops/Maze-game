# Maze Runner

A small, self-contained maze game that runs in your browser. No installation or build tools are required.

## Play

Open `index.html` in a modern web browser, then choose a difficulty and click **New maze** to start.

## Controls

- Move with the **arrow keys** or **W**, **A**, **S**, and **D**.
- On touch devices, use the on-screen directional buttons.
- Reach the glowing gold exit to finish the maze.
- Choose **Next maze** after finishing to advance to the next level.

## Features

- Randomly generated mazes at easy, medium, and hard difficulties.
- Timer, step counter, and level counter.
- Responsive layout with keyboard and touch controls.
- Built with plain HTML, CSS, JavaScript, and Canvas.
